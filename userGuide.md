## 1. Open the app

Visit: https://wg2revcom.streamlit.app/

## 2. Unlock access in Setting

1. Go to the `Setting` page.
2. Enter your password.
3. Click `Validate Password`.

Notes:

- This password is specific to you. I will create passwords for everyone.
- Access control may include different user rights/permissions in later versions.

## 3. Use Filter Comments

1. Go to `Filter Comments`.
2. Select filter options.
3. If a filter is left empty, all values are included.
4. Click `Apply` to run the filter.
5. Click `Reset` to clear filters and search text.

## 4. Search syntax

The search boxes support plain text, boolean operators, and broader searching with `*`.

Examples:

- `applicability`
- `applicability OR applicable`
- `applicab*`

## 5. Export results

Click `Export` to download filtered results as an Excel file.

## 6. Current scope

Some LLM-related functions are still under development and will be added in future updates.
